## 已完成事项

- Tauri 2 + React + TS + Vite 骨架；ESLint/Prettier/strict TS。
- SQLite 迁移与全部核心表；项目/记录/标注 CRUD。
- FFmpeg sidecar：ffprobe 元数据、截图、代理生成（进度+取消）。
- Konva 标注编辑器与归一化坐标；Canvas 合成渲染（缩略图/预览/导出）。
- 时间轴、快捷键、播放控制、视频丢失检测与重新定位（哈希比对）。
- 导出：单图/批量/HTML 报告。
- 便携项目转换：复制、校验、进度、取消。
- 测试：Vitest 13 项、Rust 5 项，全部通过。

## 风险

- GPL 版 FFmpeg 体积约 400MB，安装包较大；后续可换 lgpl/essentials 构建缩小。
- WebView2 对 HEVC/AV1 支持依赖系统解码器；代理生成兜底已覆盖。
