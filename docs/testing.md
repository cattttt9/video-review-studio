# 测试说明

```bash
npm run lint
npm run typecheck
npm run test
cd src-tauri && cargo test
```

当前覆盖：

- 前端单元测试（Vitest + jsdom）：
  - 时间格式化 / 解析（`utils/time.test.ts`）

  - 数据库迁移创建表且幂等

## 测试视频生成

```powershell
.\scripts\generate-test-video.ps1
```

生成横版/竖版/ MKV 三种小型测试视频到 `scripts/generated/`（已 Git 忽略，不提交大型素材）。

## 视频格式兼容测试要点

- H.264/AAC MP4：期望直接播放。
- MKV/AVI：期望触发代理生成后播放。
- 旋转元数据视频：期望截图方向正确（FFmpeg 自动旋转）。
