## 2026-08-05 · 初版 Bug 修复

- 文本标注：失焦/点击空白保存、Esc 取消、空文本自动删除、切换工具自动保存、Enter 换行、双击继续编辑。
- 文本预设：删除写死预设，改为用户自定义（新增/重命名/删除），localStorage 持久化；默认参数：字号 48、白色、常规、描边 0。
- 矩形/椭圆默认填充改为 0（仅边框）。
- 选择工具不再显示文本预设设置。
- 工具栏图标区分：矩形（Border）、椭圆（Aim）、文本（FontSize）、直线（Line）、箭头（ArrowRight）、选择（Select）。
- 时间轴支持点击与拖动跳转（Pointer Capture + rAF 节流）。
- 布局：右侧记录栏固定高度内部滚动，卡片不撑高窗口；空状态文案优化。
- 导出：`report.html` 与 `images/` 同级、相对路径引用；支持选择导出目录并记忆上次位置；导出后校验文件存在。
- 测试：新增报告 HTML 与文本预设持久化单元测试，共 17 项通过。

## 2026-08-05 · 时间轴与自适应布局二次修复

- 修复 Ant Design 外层容器缺少高度约束导致工作区被竖版视频或记录卡片撑高的问题；横版、竖版视频统一在可用画布内 `contain` 显示。
- 右侧记录栏保持在窗口可用高度内独立滚动，并阻止滚动到边界后继续传递给页面主体。
- 时间轴交互区域扩展到完整高度；拖动状态改用同步引用，移动时逐帧节流，松开时强制提交最终位置，避免快速拖动丢失事件或末帧。
- 跳转时立即同步播放头，播放期间使用动画帧刷新进度，暂停和播放状态下均可平滑拖动。
- 验证：ESLint 零警告、Vitest 17 项通过、Vite 生产构建通过。
- 发布：版本统一升级至 `0.1.2`；Rust 5 项测试通过，生成 NSIS 安装包 `Video Review Studio_0.1.2_x64-setup.exe`（114.18 MB）。

## 2026-08-11 · 新建记录直接进入标注

- 修复新建记录自动选中后，被项目统计刷新触发的记录重载清空选中状态的问题。
- 新建含截图记录提交成功后，直接进入该截图的标注界面，无需在右侧记录栏中再次查找和点击。
- 创建按钮根据是否保存截图显示“创建并标注”或“创建”，并补充下一步操作提示。
- 标绘或文字新建完成后自动选中并切回选择工具，可立即拖动调整位置。
- 补齐画笔轨迹、直线和箭头的整体移动，并将移动结果纳入撤销、自动保存及图片边界约束。
- 选择工具下点击图片空白处会取消当前选中，矩形等对象的移动/缩放边框不再持续显示。
- 文字输入框不再强制使用半透明白底；文字背景关闭时完全透明，启用时遵循所选背景色及不透明度。
