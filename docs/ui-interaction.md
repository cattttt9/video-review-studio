# 交互设计

## 首页

- 新建项目：填写名称 → 可选选择视频 → 选择保存目录（默认文档目录）→ 创建后进入工作台。
- 视频拖入首页自动进入新建项目流程。
- 最近项目卡片：项目名、视频名、记录数、最近打开时间、视频状态；支持打开、删除（移入回收目录）。
- 打开项目：选择项目目录（含 project.json + project.db）。

## 主工作台布局

```text
┌──────────────────────────────────────────────────┐
│ 顶栏：返回 / 项目名 / 保存状态 / 代理 / 便携 / 导出 / 新建记录 │
├──────────┬──────────────────────────┬────────────┤
│ 标注工具 │ 视频播放器 / 静态截图编辑区 │ 复盘记录栏   │
│ + 样式   │ 播放控制条                 │ 大缩略图卡片 │
│          │ 时间轴                    │ 排序/筛选   │
├──────────┴──────────────────────────┴────────────┤
│ 状态栏：分辨率 / 帧率 / 当前时间 / 记录数 / 后台任务      │
└──────────────────────────────────────────────────┘
```

## 新建记录流程

1. 播放视频，暂停在关键画面（或点击时间轴定位）。
2. 点击“新建记录”（快捷键 N）。
3. 表单默认时间取当前播放时间；可改为时间区间并设置代表时间。
4. 勾选“保存代表截图”时，创建后自动用 FFmpeg 截图。
5. 保存后中间区域切换为静态截图编辑状态，可添加标注。

## 查看记录

- 单击右侧卡片：选中、视频跳转到代表时间并暂停、中间区域加载截图与标注。
- 双击缩略图或点击放大按钮：打开高分辨率合成预览（滚轮缩放、拖动平移、双击复位、前后条切换、进入编辑）。

## 标注编辑

- 工具切换：工具栏按钮或快捷键（P/A/R/T）。
- 空白处双击：创建文本并进入输入状态；Ctrl+Enter 或失焦结束输入。
- 选择工具下：单击对象选中；拖动移动；矩形/椭圆/文本可通过锚点缩放；直线/箭头拖端点。
- Delete 删除选中标注；Ctrl+Z / Ctrl+Y 撤销重做；Ctrl+S 保存。
- 样式面板按工具显示描边、填充、文本样式；文本支持预设（白字黑边、黄字黑边、红底白字、半透明黑底白字）。

## 重新截图 / 修改代表时间

- 编辑记录时勾选“重新截取代表截图”，可同时选择保留或清空原有标注。
- 修改代表时间后重新截取，截图文件名沿用 `record-{id}-source.png`，旧图被覆盖（不会残留）。

## 时间轴

- 点击轨道跳转；标记：竖条=时间点，色块=区间；红色播放头跟随播放。
- 放大/缩小以播放头为中心，适应按钮恢复全时长。

## 异常状态

- 原视频丢失：顶部警告条，提供“重新定位视频”；已存截图与文字仍可查看，禁止新建截图与代理。
- 代理生成/便携转换：进度显示在顶栏与状态栏，可取消，取消后清理临时文件。
- 数据库写入失败：保存状态变红，错误信息说明原因。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Space | 播放/暂停 |
| ← / → | 逐帧后退/前进 |
| Shift+← / → | 快退/快进 5 秒 |
| N | 新建记录 |
| Delete | 删除选中标注 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存标注 |
| T / A / R / P | 文本 / 箭头 / 矩形 / 画笔 |
| Esc | 退出当前工具或取消选择 |

输入框、文本域、富文本编辑状态下快捷键自动忽略。
