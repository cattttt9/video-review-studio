# 需求说明

## 产品目标

开发一个 Windows 本地视频分析与复盘工具，服务以下场景：

- 视频拉片
- 游戏对局复盘
- 教学视频分析
- 操作录像审查
- 会议 / 演示录像重点标注

核心价值：快速定位关键时刻 → 自动截取代表画面 → 静态截图标注 → 通过缩略图记录流复盘、检索与报告导出。

## 用户场景

1. 玩家把对局录像拖入应用，暂停在关键团战画面，新建记录并画箭头、矩形和文字说明。
2. 教练按时间顺序浏览右侧标注卡片，双击放大查看细节，导出 HTML 复盘报告发给队员。
3. 视频被移动后项目仍可打开，重新定位视频后继续工作。

## 已确认需求

### 项目模型

- 一个项目绑定一个视频；一个视频可有多条复盘记录。
- 默认引用原视频路径；可转换为便携项目（视频复制进项目目录）。
- 打开项目检查原视频存在性；丢失时支持重新定位。

### 记录模型

- 时间点记录：`start_time_ms == end_time_ms == representative_time_ms`。
- 时间区间记录：开始 / 结束 / 代表时间，代表时间必须在区间内。
- 每条带图记录只长期保存一张原始代表截图（PNG）；标注对象独立保存，显示/导出时合成。
- 支持重新截取、修改代表时间、保留或清空标注、无截图记录。

### 标注

- 第一版工具：选择、画笔、直线、箭头、矩形、椭圆、文本、删除、撤销、重做。
- 对象可选中、拖动、缩放、调整端点、调整层级、删除、复制、样式修改、文本重新编辑。
- 所有几何使用归一化坐标（相对视频画面），正确处理横竖版、黑边、窗口缩放、高 DPI。

### 视频

- MP4 / MOV / MKV / WebM 等常见格式；无法直接播放的编码通过 FFmpeg 生成代理视频。
- 原视频不得修改；截图与元数据优先基于原视频。
- 支持长视频与 4K，不得一次性加载整个视频进内存。

### 右侧记录栏

- 合成标注缩略图为主，大图小字；单击选中并跳转，双击或按钮放大。
- 按视频时间 / 创建时间排序，正序 / 倒序；支持编辑、复制、删除。

### 导出

- 单条原始截图、单条标注图、批量图片、HTML 图文报告（可选 PDF via 浏览器打印）。
- HTML 使用相对资源路径，整个导出目录移动后仍可打开。

## 第一版范围

- Windows 10/11 本地桌面应用；无登录、无云同步、无遥测。
- 所有数据保存在本地；日志不记录敏感路径。

## 非目标（第一版不实现）

多视频项目、云同步、账号、多人协作、在线分享、视频剪辑/拼接、音轨编辑、带标注视频导出、复杂动画、AI 自动识别、语音转文字、插件市场、移动端、远程数据库、遥测与广告。

## 验收标准

- 可安装运行；项目/记录/标注关闭后重开完整。
- 横版竖版均正确；标注窗口缩放不漂移。
- 代理生成、截图、缩略图、导出均有进度与错误提示。
- 数据库迁移可重复执行；异常退出不丢已保存数据。
- 最终交付包含源代码、文档、测试、本地 Git 阶段提交、Windows 安装包。

## 后续候选功能

- 带标注视频导出、字幕/语音转写、AI 画面识别、多项目/多视频、协作与分享。
